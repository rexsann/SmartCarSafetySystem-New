# Sprint 1 Plan — Smart Car Safety

## Sprint Goal

Menyiapkan fondasi pengembangan Smart Car Safety, yaitu sistem pemantauan kadar gas karbon monoksida (CO) di dalam kabin mobil menggunakan ESP32 dan sensor MQ-7.

## Sprint Backlog

| ID | Task | Hasil yang Diharapkan | Status |
|---|---|---|---|
| SP1-01 | Menentukan kebutuhan perangkat keras | Daftar ESP32, sensor MQ-7, OLED, LED, dan buzzer | To Do |
| SP1-02 | Merancang koneksi perangkat keras | Diagram koneksi komponen | To Do |
| SP1-03 | Menyiapkan lingkungan pemrograman ESP32 | Proyek siap untuk pengembangan firmware | To Do |
| SP1-04 | Merancang pembacaan kadar CO | Rencana pembacaan data sensor | To Do |
| SP1-05 | Merancang indikator keamanan | Rencana status Aman, Waspada, dan Bahaya | To Do |
| SP1-06 | Menyiapkan pengujian awal | Daftar skenario pengujian sensor dan indikator | To Do |

## Definition of Done

- Task memiliki hasil yang dapat diperiksa.
- Perubahan disimpan melalui commit Git.
- Perubahan diajukan melalui Pull Request.
- Pull Request diperiksa dan di-approve oleh anggota tim lain.
- Pekerjaan yang belum diimplementasikan tetap berstatus To Do atau In Progress.
