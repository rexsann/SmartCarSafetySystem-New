# Sprint Backlog — Smart Car Safety

## Tujuan Sprint

Menyusun fondasi pengembangan Smart Car Safety melalui pendokumentasian kebutuhan produk, pembagian pekerjaan, dan penetapan alur kolaborasi menggunakan GitHub.

## Rencana Pekerjaan Sprint

| ID | Pekerjaan | Hasil yang Diharapkan | Prioritas |
|---|---|---|---|
| SB-01 | Menyusun Product Backlog | Daftar kebutuhan dan prioritas fitur tersedia. | Tinggi |
| SB-02 | Menyusun struktur dokumentasi Agile | File dokumentasi tersusun secara konsisten. | Tinggi |
| SB-03 | Menyusun panduan kontribusi | Anggota memahami aturan branch, commit, dan Pull Request. | Tinggi |
| SB-04 | Menyiapkan branch pengembangan | Branch `develop` tersedia sebagai tempat integrasi pekerjaan. | Tinggi |
| SB-05 | Menyiapkan branch dokumentasi | Perubahan dokumentasi dikerjakan pada `docs/agile-documentation`. | Tinggi |
| SB-06 | Meninjau perubahan dokumentasi | Isi file diperiksa sebelum diajukan melalui Pull Request. | Sedang |

## Pembagian Pekerjaan

Pembagian pekerjaan dilakukan berdasarkan anggota tim dan kesepakatan bersama. Setiap pekerjaan perlu memiliki penanggung jawab dan status yang diperbarui secara berkala.

## Definition of Done

Pekerjaan dinyatakan selesai apabila:
- Hasil pekerjaan sesuai dengan kebutuhan yang disepakati.
- Perubahan sudah diperiksa.
- Dokumentasi terkait sudah diperbarui jika diperlukan.
- Commit memiliki pesan yang menjelaskan perubahan.
- Pull Request sudah ditinjau dan disetujui sesuai aturan tim sebelum di-merge.

## Catatan

Daftar pekerjaan, penanggung jawab, dan status harus disesuaikan dengan aktivitas sprint yang benar-benar disepakati dan dilakukan oleh tim.
